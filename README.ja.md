# Aegis Desk

**[한국어](README.ko.md) · 日本語 · [English](README.md)**

個人のClaude・Gemini・OpenAI APIを、明示した作業範囲で利用するデスクトップアプリです。Spacekeeperとは別のプロジェクトです。

**0.1は個人向けの初期版です。ウイルス対策、システム全体のファイアウォール、OSサンドボックスではありません。** このアプリ内のリクエストと選択ファイルのみ管理します。他のAIアプリやブラウザーは制御しません。

## 起動と使い方

[Releases](https://github.com/ddossss/aegis-desk/releases)から対応するZIPを入手してください。Macは `Aegis Desk.app`、WindowsはZIP全体を展開して `Aegis Desk.exe` を起動します。Node.jsの別途インストールは不要です。Mac版はアドホック署名で未公証、Windows版は未署名です。

1. サイドバーで日本語・한국어・Englishを選択します。
2. プロジェクトフォルダーを登録し、ファイル送信を許可するAIを設定します。最初はすべて無効です。
3. AI接続で自分のAPIキーを保存します。キーだけ保存してモデル一覧を取得し、モデルを選んで再保存できます。
4. AIワークベンチでファイルを1つ選び、送信内容に同意してリクエストします。
5. 変更前後を確認して適用します。履歴から復元でき、他で変更されたファイルは上書きしません。

自動編集も選択した既存ファイルだけに適用します。コマンド実行、任意のURL、MCPの実行、AIによる権限変更は提供しません。停止ボタンでリクエストを中断し、変更案を無効化できます。送信済みのデータは取り消せません。

OSのセキュリティ状態は読み取り専用です。MCP設定の点検は安全性の認証ではありません。キーはOS機能で暗号化しますが、Windowsでは同一ユーザー権限の他のプログラムから完全には隔離されません。復元用コピーには元のファイル内容が含まれ、個別には暗号化されません。

活動ログにはキー、リクエスト、ファイル内容を記録しません。許可されたリクエストと選択ファイルだけをAIプロバイダーに直接送ります。API料金はチャットの契約とは別の場合があります。
