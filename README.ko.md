# Aegis Desk

**한국어 · [日本語](README.ja.md) · [English](README.md)**

**Aegis Desk(이지스 데스크)**는 내 AI가 작업할 범위를 정하는 별도 데스크톱 앱입니다. Spacekeeper는 파일 정리에 집중하고, Aegis Desk는 본인의 Claude·Gemini·OpenAI API 연결과 선택 파일의 변경을 관리합니다.

**0.1은 개인용 초기 버전입니다. 백신·시스템 전체 방화벽·외부 AI 앱 통제 기능은 제공하지 않습니다.** 이 앱에서 전송하는 요청과 파일에만 권한 검사를 적용합니다. 전체 위협 방어가 완성된 제품으로 사용하지 마세요.

## 실행

[Releases](https://github.com/ddossss/aegis-desk/releases)에서 운영체제와 CPU에 맞는 ZIP을 다운로드하세요. Mac은 `Aegis Desk.app`, Windows는 ZIP 전체를 풀고 `Aegis Desk.exe`를 실행합니다. 별도 Node.js 설치는 필요 없습니다. 초기 Mac 배포판은 ad-hoc 서명이며 공증되지 않았고, Windows 배포판은 미서명입니다.

## 사용 순서

1. 사이드바에서 한국어·日本語·English를 선택합니다.
2. **작업 공간**에 프로젝트 폴더를 등록합니다. 처음에는 모든 AI로의 전송이 꺼져 있습니다.
3. 선택 파일을 보낼 AI를 허용하고, 기본값인 **변경 전 검토**로 시작합니다. 권한 확대는 운영체제 확인 창에서 확인합니다.
4. **AI 연결**에 본인의 API 키를 저장합니다. 모델 ID는 비워 둔 채 키를 먼저 저장하고, 모델 목록에서 사용 가능한 모델을 골라 다시 저장할 수 있습니다. API 요금은 채팅 서비스 구독과 별개일 수 있습니다.
5. **AI 작업실**에서 파일 하나를 선택하고 요청을 보냅니다. 실제 전송 대상은 요청 내용과 선택 파일입니다.
6. 변경 전후 내용을 확인하고 적용합니다. **활동과 복원**에서 이전 내용을 복원할 수 있으며, 다른 프로그램이 수정한 파일은 덮어쓰지 않습니다.

선택 파일 자동 수정도 지원하지만 해당 파일에만 적용합니다. AI에게 임의 경로 선택·명령 실행·추가 도구 호출·권한 변경 기능을 주지 않습니다. API 키·개인키 등으로 보이는 내용, 숨김 파일, 링크, 주요 설정 파일은 제외합니다. 비밀정보 탐지는 모든 민감한 내용을 찾아내는 기능은 아닙니다.

**AI 작업 중단**은 진행 중인 요청을 취소하고 변경안을 무효화합니다. 이미 서비스에 전송된 정보는 회수할 수 없습니다. 중단 상태는 재실행 후에도 유지하며 복원은 계속 사용할 수 있습니다.

## 보안과 데이터

- macOS의 Gatekeeper·방화벽·FileVault, Windows의 Defender·방화벽 상태를 읽습니다. 설정은 변경하지 않으며 확인할 수 없는 값은 그대로 표시합니다.
- MCP 설정 JSON에서 위험 신호를 찾지만 서버를 실행하거나 안전을 인증하지 않습니다.
- 저장된 API 키는 운영체제 기능으로 암호화합니다. Windows에서는 같은 사용자 권한의 다른 프로그램까지 격리하지는 못합니다.
- 활동 기록에는 키·요청·파일 내용을 저장하지 않습니다. **복원 사본에는 원래 파일 내용이 들어가며 별도로 암호화되지 않습니다.** 로컬 상태 폴더를 보호하고, 복원이 필요할 때는 보관하세요.
- 클라우드 AI에는 허용한 요청과 파일이 전송됩니다. 별도의 Aegis 서버나 분석·추적 SDK는 없습니다.
- 다른 프로그램과의 동시 파일 수정 경합, 같은 사용자/관리자 권한의 악성 프로그램, 클라우드 서비스 자체의 위험까지 방어한다고 보장하지 않습니다.

실제 로컬 상태 폴더는 앱에서 열 수 있습니다. 개발 시에는 `codex-work/state`를 사용합니다. 자세한 기술 범위와 빌드 명령은 [영문 안내](README.md), [보안 모델](SECURITY.md), [검증 기록](docs/VALIDATION.md)에 있습니다.
